# 屏幕/纸张照片还原

## 先定义页面

照片的像素尺寸不是幻灯片尺寸。区分截图、海报、屏幕照片和纸张照片。对拍照图记录页面四角（左上、右上、右下、左下）以及实际可见的区域；四角被裁掉时记录推定位置，不能称为测得值。长宽比优先从原 PPT/PDF、已知页面规格或明确边界得出；仅能推定时注明依据。

笔记本边框、桌面、视频会议说话提示和共享控制条通常不属于页面内容。不要把它们重建到 PPT。浮层盖住的文字、标识或数值不作无依据补写。

## 技术预处理

先 `view_image` 查看本地源图，再用确定性透视变换得到便于比对的平面参考。透视与裁切属于文档像素预处理，不能生成新文字，也不能让低分辨率截图恢复不存在的细节。原文件始终保留。

```bash
python scripts/prepare_reference.py \
  --input photo.jpg --out /absolute/task/private/rectified.png \
  --quad 120 10 1180 20 1220 690 80 700 \
  --width 1280 --height 720 \
  --crop evidence-01=70,330,410,420 \
  --asset-dir /absolute/task/assets \
  --geometry-note '16:9为依据可见页面推定的比例；通话浮层排除，遮挡文字未推断。'
```

`quad` 是应用 EXIF 方向后的源图坐标，顺序为左上、右上、右下、左下。`crop` 是校正后画布的裁切框。脚本输出来源 SHA-256、四角、目标尺寸、裁切坐标及裁切素材哈希。四角不可靠时不要做强行拉伸，可直接保留原裁切图。

## 小字和证据

把图片分成三类区域并记录：

| 区域 | 处理方式 |
| --- | --- |
| 清晰主标题、主要正文、数字 | 逐块人工视觉核对，转为可编辑文本 |
| 内嵌聊天/通报截图、小字号证据表格 | 从实际源图裁切，作为独立图片保留，标记 `sourceRole: evidence-screenshot` |
| 被遮挡、过曝、裁掉或无法辨认的内容 | 记录位置与限制；保留可见源图，必要时询问原文件，不推断隐藏信息 |

不应把截图模糊小字录成假精确数据，也不应用重新生成的聊天截图代替来源。照片中的摩尔纹和亮度不均属于拍摄现象，重建页面背景时不需要仿制；截图证据仍保留其原始像素。
