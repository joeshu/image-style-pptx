# 图标来源

本目录 SVG 来自已安装的 Lucide v1.8.0。
项目：https://lucide.dev ，源码：https://github.com/lucide-icons/lucide 。
仅调整描边颜色；许可证见 LUCIDE-LICENSE.txt。
图标是参考图的近似替代，没有将其宣称为原图标素材。

`icons/` 是1.3版起默认使用的统一图标集，保持24×24 viewBox、2px描边、圆形线端和连接、无填充；默认蓝色。`icons/catalog.json` 记录全部30枚图标的名称、中文语义、来源版本和源文件哈希。`icons/preview.svg` 为这些已有图标的排版预览。

本目录根层的 SVG 保留用于旧路径兼容；新的版式使用 `type: icon` 及 `icons/`。红金示例已迁移到统一图标入口，仍使用其红/白主题色。
